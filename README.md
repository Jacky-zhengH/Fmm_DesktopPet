# fmm 桌宠补完计划 · Fmm DesktopPet

这是一只 **芙眠眠nemu** 桌宠，基于已有的 Python / PySide6 源码修改。先把日常用着不顺手的地方修好，再慢慢加功能。

芙眠眠nemu是 B 站助眠区的 UP 主，很推荐她的助眠内容，感兴趣可以搜搜看。

## 现在能做什么

- 放在桌面上，点击会开心，能拖着走，也会自己眨眼、走动和睡觉。
- 鼠标在角色身上停留片刻，打开时钟、喂食、设置三个气泡入口；小图标沿弧线排列，会根据屏幕位置切换到上、下、左、右。
- 在设置面板调整大小，范围 80%～200%；也可以按住 Ctrl 滚动滚轮。
- 切换像素清晰或平滑显示，开关自主走动，记住上次的位置和大小。
- 替换 PNG 动作素材后，可以在设置面板重新加载。
- 喂食先做概念面板：左右滑动选点心、加减份数、预览反馈；睡着时先留点心，不唤醒。演示数值不存档。
- 悬停时钟图标看时间，点击设定时；支持自定义时分秒、独立倒计时、暂停和取消，开始后菜单自动收起，到时芙芙会来到屏幕中间提醒，随后走回原位。
- 已修复走路变小，靠近任务栏/屏幕边缘松开后会吸附；拖走可以解除，也可以在设置中开关。

当前版本 0.1.3，整理了近期时钟显示和气泡的小修订：时间在时钟图标附近透明显示，日期和星期由芙芙的紧凑语言气泡报出，边角位置会避让菜单。常用操作见 [简易功能指引](docs/QUICK_GUIDE.md)。

下一版 0.1.4 先修素材，再加入拎起轻晃、连续点击生气和左右探头，见 [工作方案](docs/plans/0.1.4.md)。六张修复候选已完成，正在审图，尚未接入程序；新动作仍待制作。当前运行版为 `0.1.3`。

## 怎么打开

直接使用可在 [Release](https://github.com/Jacky-zhengH/Fmm_DesktopPet/releases/latest) 下载 `Fmm-DesktopPet-v0.1.3.exe` 或便携 ZIP，不需要安装 Python。个人设置保存在 EXE 旁的 `.user` 文件夹，升级时保留它即可。

以后每次发布都会提供源码包 `-source.zip`、EXE 便携包 `.zip`，两者都带功能指引；也可单独下载 EXE 或 `-Guide.txt`。发布页面会简要列出功能、改动和运行方式。

要运行源码，新电脑第一次需要先装 Python 3.10+，再双击 `setup.bat`。

**平时双击根目录的 `run.bat` 就行。** 如果桌宠已经开着，先退出再启动，避免开出好几只。右键可直接睡觉/叫醒或退出，气泡设置里也有这些操作。鼠标移开后菜单会收起；Esc 可关闭菜单和面板，托盘图标也能打开菜单。

界面预览见 [0.1.2 实际 Qt 绘制](image/review/0.1.2/ui.png)。

更多操作见 [源码使用说明](docs/SOURCE.md)。
