# fmm 桌宠补完计划 · Fmm DesktopPet

这是一只 **芙眠眠nemu** 桌宠，基于已有的 Python / PySide6 源码修改。先把日常用着不顺手的地方修好，再慢慢加功能。

芙眠眠nemu是 B 站助眠区的 UP 主，很推荐她的助眠内容，感兴趣可以搜搜看。

## 现在能做什么

- 放在桌面上，点击会开心，能拖着走，也会自己眨眼、走动和睡觉。
- 鼠标在角色身上停留片刻，打开时钟、喂食、设置三个气泡入口；菜单会根据屏幕位置换侧或横排。
- 在设置面板调整大小，范围 80%～200%；也可以按住 Ctrl 滚动滚轮。
- 切换像素清晰或平滑显示，开关自主走动，记住上次的位置和大小。
- 替换 PNG 动作素材后，可以在设置面板重新加载。
- 喂食先做概念面板：选点心、加减份数、预览反馈；演示数值不会写入存档。
- 时钟面板可设 5 / 15 / 30 分钟计时，到时弹出气泡提醒。
- 已修复走路变小，靠近任务栏/屏幕边缘松开后会吸附；拖走可以解除，也可以在设置中开关。

呆毛里仍有背景残留，现有动作也不多，后面还会继续补。已验收版本为 `0.1.1`；本分支是 `0.1.2` UI 试用版，等试用后再合并。

## 怎么打开

新电脑第一次运行，需要先装 Python 3.10+，再双击 `setup.bat`。

**平时双击根目录的 `run.bat` 就行。** 如果桌宠已经开着，先退出再启动，避免开出好几只。新版从气泡设置中退出，旧版仍用右键。鼠标移开后菜单会收起；Esc 可关闭菜单和面板，托盘图标也能打开菜单。

界面预览见 [0.1.2 实际 Qt 绘制](analysis/ui_0_1_2_preview.png)。

更多操作见 [源码使用说明](deskpet/deskpet/README.md)。
