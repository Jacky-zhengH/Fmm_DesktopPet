# 芙眠眠参考素材

这里存放后续魔改使用的原始形象图、表情参考、姿势参考、动画参考和生图结果。

- 可以直接放图片；建议保留原图，不覆盖原文件。
- 文件名可以注明用途，例如 `芙眠眠_正面参考.png`、`芙眠眠_睡觉参考.png`。
- 如有多个版本，可以自行建立 `reference/`、`generated/`、`animation/` 子目录。
- 本目录目前只是素材收集区，不会被现有桌宠自动加载。
- 源码版实际读取的运行素材位于 `app/assets/sprites/`。
- 现有便携 EXE 内置自己的素材；修改外部 PNG 不会自动更新它。

后续制作动画时，需要统一人物比例、画布、脚底基线和透明背景；序列帧从 `_0.png` 连续编号。程序默认显示尺寸为 200，可在 160～400 范围调整；这不是原图必须绘制成 200×200 的要求。新增姿势还需明确身体基准和支点，避免按每帧外框改变人物大小。

0.1.4 的修图、生图与审图流程见 [素材制作方案](../docs/ART_WORKFLOW_0_1_4.md) 和 [提示词模板](../docs/art/PROMPTS_0_1_4.md)。候选图放 `image/candidates/0.1.4/`，认可后才接入运行目录；原参考图不覆盖。

用户上传的图一已保存为 `fmm_master_reference.jpg`；图二问题参考为 `ahoge_white_region_reference.jpg`。用途与呆毛区域分析见 `REFERENCES.md`。
