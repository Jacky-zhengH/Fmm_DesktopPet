# 0.1.2 气泡界面

仍按用户手绘图保留时钟、喂食、设置三个入口。本轮根据试用反馈缩小图标并改为弧形：靠近屏幕边缘时，按空余位置切换到角色上、下、左、右。原角色 PNG 不变。

鼠标停留约 350 ms 展开，移开约 900 ms 收起；面板打开后可停留阅读。二级面板互斥，拖动、Esc 或切到其他应用会收起。菜单限制自主走动，但动画更新继续，待机呼吸、眨眼、睡眠呼吸和 Zzz 都会动。右键恢复两个快捷项：蓝色月亮的睡觉/叫醒，与红色电源的退出，中间有分隔线。设置面板仍保留全部设置，托盘也能找回入口。

悬停时钟图标只显示小号 HH:mm 文字，无背景框。点击才打开定时器设置：5/15/30 分钟预设，以及 00:00:01～23:59:59 的自定义时分秒。启动后菜单和设置面板自动收起，出现可拖动的独立小窗口，支持暂停、继续和取消。关闭设置面板不影响计时，关闭独立窗口会取消；退出程序后不保留。

计时到期后会暂时解除吸附，用走路动作向当前屏幕可用区域中央移动，到达后显示提醒。拖动、大小对话框或右键菜单正在使用时先等待；用户在途中拖动则暂停移动，松开后继续提醒。提醒气泡显示约 6.5 秒后，芙芙会走回到期出发前的位置，恢复原来的屏幕/任务栏吸附。睡着时到期会起身移动，返回后继续睡。提醒已显示或正在返程时主动拖动她，会取消自动返回，以手动摆放的位置为准。

喂食仍是概念预览。面板缩为约 250×360 个逻辑像素；零食用滑动轮播显示，中央完整、相邻露出部分。左右按钮或键盘左右键切换，数量仍是 1～3 份。投喂说明固定高度，避免长文字挤动按钮。每次重新打开重置演示数值，不写入养成存档。

清醒时预览会增加演示状态并说“谢谢你的小点心～”；睡着时改为“先留一份”，不增加状态、不唤醒，说“呼…点心留到醒来再吃吧。”定时开始、面板提示、独立窗口说明及到时提醒也随睡眠状态变化。

对话改为优先贴近角色头顶，再考虑侧面与下方，不能再围绕“角色＋面板的大包围框”定位。用户截图中的远距离气泡由旧定位方式造成；投喂后长说明还会改变布局，本轮一并调整。

验证：47 项真实 Qt 自动检查通过，覆盖四向弧形布局、悬停文字、轮播动画/键盘、快捷菜单动作、独立计时暂停/继续/取消、自定义时间、到期移动/拖动打断、睡眠差异、气泡距离和原有缩放吸附。Windows 原生入口启动及完整计时流程已运行，实测设置后收起菜单、到期走到中央、气泡结束后返回并恢复睡眠和任务栏吸附，应用自身绘制图已查看；未声称完成所有原生鼠标命中、多屏热插拔或混合 DPI 验收。

预览脚本 analysis/preview_ui_0_1_2.py 可加 --feedback、--sleep、--timer 秒数、--alarm；--native 使用 Windows 窗口，--exit-after-render 捕获后退出，均不加载/保存个人设置。常规测试仍双击根目录 run.bat。
