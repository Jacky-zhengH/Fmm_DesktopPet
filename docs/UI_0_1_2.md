# 0.1.2 气泡界面

依据用户的手绘概念图，角色仍是主体，三个圆形入口为时钟、喂食、设置。暖黄色、浅绿色、淡粉色区分入口，面板用奶油底色。图中的虚线轮廓理解为候选排布位置，不绘制到桌面上。

鼠标在角色上停留约 350 ms 展开菜单。通常竖排在右侧，靠右则换到左侧；两侧不足时横排。菜单和面板按屏幕可用区域定位，避免进入任务栏。打开菜单暂停自主走动，跨过菜单间隙有 900 ms 宽限；面板打开后可以停留阅读。拖动、Esc 或切到其他应用会收起；托盘可找回入口。原来的角色右键菜单已移除。

时钟、喂食、设置一次只开一个二级面板，再点当前入口会关闭。设置承接睡觉、大小、像素显示、走动、吸附、重载与退出，大小面板保留原来的预览和取消还原。

喂食是概念面板。温牛奶、小饼干、草莓糕可选，数量 1～3 份；点击“预览投喂”更新演示饱腹感/心情，并显示短句。每次重新打开面板回到初始值，完全不写入养成存档。没有饥饿衰减、离线结算、库存或真正的吃东西动作。

时钟显示本地时间，提供 5/15/30 分钟单个计时；重新选择会替换旧计时，可取消。关闭面板仍计时，到时气泡提醒；退出程序后不保留。暂未加入整点报时、声音或系统通知。

实现仍使用 PySide6 QWidget / QPainter。气泡入口、二级面板和对话使用独立透明窗口，避免被角色原生掩码裁掉。角色素材不变。图标为代码绘制，无新增生成素材依赖。

验证：33 项自动检查通过，覆盖面板互斥、点击操作、演示数据隔离、计时、拖动、旧缩放与吸附、四角/负坐标屏幕/窄屏布局。Windows 原生显示已查看；桌面测试工具对透明子窗口按钮的定位有限，原生自动点击未计作通过。多屏实机热插拔和混合 DPI 仍需后续试用。

预览脚本 `analysis/preview_ui_0_1_2.py` 直接捕获实际 Qt 控件，生成 `analysis/ui_0_1_2_preview.png`；`--native` 打开临时测试窗口，4 分钟后退出，不读取或保存个人配置。常规测试入口仍是根目录 run.bat。

目标版本 0.1.2，关联 Issue #7；用户试用验收前保留在功能分支，不覆盖 v0.1.1。
