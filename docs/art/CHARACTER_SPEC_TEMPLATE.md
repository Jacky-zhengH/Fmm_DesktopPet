# 芙芙动作素材基准卡

状态：待填写与审定。用于 A01；这张卡不代表新素材已通过审图。

## 形象与参考

- 身份参考：`image/fmm_master_reference.jpg`。母图粉色底是背景，不属于角色。
- 线条与配色参考：先认可一张清理白底后的正面基帧，再填写具体文件名与 SHA256。
- 正面画面左眼绿、右眼红；爱心发饰在正面画面右侧。转身或侧看按角色自身方位和透视处理，不整图镜像改身份。
- 保留粉色长发、呆毛、女仆头饰、爱心发饰、裙装、头身比例。大幅表情也不改脸型和主要发束。
- 现有 PNG 不是已拆好的骨骼稿。分层后需补被遮住的发丝和身体，不把缺失区域当成模型自动完成的部分。

## 每个动作填写一次

| 字段 | 待填内容 |
|---|---|
| 动作编号 / 版本 | 例如 drag_front_r01 |
| 基帧文件 / 哈希 | 认可后填写；未经认可不写 accepted |
| 画布尺寸 | 同一动作整组固定；512×512 可作制作起点，补发梢和摆动若需更大空间，整组调整 |
| 实际像素颗粒 | 比较原图后确定；不把 512 的文件边长当作已确认的绘制网格 |
| 身体基准框 | 只用于角色比例，注明坐标；不要把爱心和怒气符号算进身体 |
| 脚底 / 身体基准锚点 | x、y，左上为原点，单位为源图像素 |
| 拎起支点 / 抓取补偿 | 只在拖动动作需要时填写；鼠标按下位置不应突然跳到支点 |
| 探头边缘锚点 | 只在探头动作填写；身体仍完整画出，由程序决定隐藏部分 |
| 朝向与特征 | 屏幕方向与角色自身方向分别写清楚 |
| 帧清单 | 全组同画布，输出 _0、_1……连续编号；另存 key/inbetween 标签 |
| 播放 | 试验 fps、是否循环、动作结束规则；最终以手感和位移匹配验收 |
| 修改区域 | 脸、手脚或发梢等；原图必须保留的区域同时注明 |
| 透明与安全边距 | 检查真实 Alpha、封闭空隙、摆动范围；新增素材不贴边截断 |
| 审图记录 | 用户确认、日期、待修点、候选版本 |

补发梢或改姿势后非透明外框会变化；先标定身体与锚点，再接入程序。否则现有按内容框统一高度的算法可能把头发变化误认为身体变大，再把整个人缩小。

## 接入前检查

1. 在白、深灰和棋盘背景检查呆毛孔洞、发梢、头饰、高光；透明棋盘只用于预览，不烘焙进 PNG。
2. 检查眼睛颜色、发饰位置、手脚数量和裙装细节；关键特征错误直接退回。
3. 检查所有帧的头部大小、身体基准和脚底；脚离地应是动作设计，不是导出偏移。
4. 在 160 / 200 / 300 / 400 显示大小看循环，既看单帧，也看过渡和回到第一帧。
5. 查看新姿势与 idle、sleep、walk 切换，不突然改变体型；旋转时不裁呆毛或发梢。
6. 通过前后对照后才接入运行目录，并更新动作元数据。接入属于后续程序任务，本卡不会自动修改桌宠。
