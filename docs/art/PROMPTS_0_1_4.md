# 0.1.4 图像编辑提示词模板

以下为待试提示词，不是已生成素材。一次只提交一个动作或一个局部修改；模型不提供的 mask、seed 或 alpha 功能，不用提示词假装已经具备。真正生成前复核每张图的用途。

## 参考图分工

- 图 A：`image/references/fmm_master_reference.jpg`，锁定人物身份、头身、粉发、异色瞳和服装；粉色背景不是人物的一部分。
- 图 B：已认可的干净运行图，锁定现有线条、色板和颗粒感；未修白底的原图要注明问题，避免模型复刻残留。
- 图 C：用户或 PS 画的动作草图，只规定姿势与方向，不借用其颜色和人物设计。
- 编辑目标：需要修改的那一张原图 / 扩展画布副本；如果同时提供参考和目标，要分别说清楚。

模型限制参考图数量时，按任务保留最有用的输入；局部修图优先保留目标，关键姿势优先保留身份参考和草图。

## 通用固定要求

```text
用途：芙眠眠 nemu 桌宠的二维角色动作素材；单个角色、单个姿势。
图 A 规定角色身份，图 B 规定现有像素风格，图 C 仅规定动作。
保持粉色长发、呆毛、女仆头饰、爱心发饰、异色瞳、裙装和原头身比例。
正面参考的画面左眼为绿色、右眼为红色；如改变朝向，请按人物自身左右与透视保持身份特征，不整体镜像配饰。
保持现有描边粗细与像素颗粒，不新增写实纹理、3D 材质、渐变光照或其他人物。
角色全身完整进入画面，发梢、呆毛、手脚不能贴边裁断，四周预留足够透明空间。
输出一张独立图片，不要九宫格、拼贴、字幕、文字、界面或画出来的棋盘格。
服务支持时输出真实透明背景；不支持时另行约定纯色底，不能声称已有 Alpha。
```

同一轮只改变一个关键条件。局部修复任务使用下方更严格的局部要求，不为了统一格式强迫所有任务重新生成全身。

## P1：走路发梢局部补全

```text
用途：修复已有桌宠 PNG 的横向截边。
编辑目标为图 B 的扩展画布副本；图 A 仅用作发型和配色参考。
只在标注区域补全右下长发被画布截断的轮廓和少量内部发丝，使发梢自然闭合。
新头发延续邻近的粉色填色、描边颜色、线条粗细和原有发束方向。
保留目标原图的脸、异色瞳、发饰、衣服、手脚、比例和站位；不重画或美化其他部分。
保持原画布尺寸和已存在内容的位置，不裁切，不缩放人物，不新增背景或光影。
输出单张候选图。此处是合理补画缺失部分，不是复原未知的原始笔画。
```

模型可能仍会改到其他区域。拿到图后只提取认可的补画区域，与原图非编辑部分合成；不要只依赖“保持不变”这句话。

## P2：拎起中立关键姿势

```text
沿用通用固定要求，制作“轻轻被拎起”的中立关键姿势。
角色轻微惊讶，手脚放松向下，裙摆和后发自然垂落；不拉长脖子或改变头身比例。
头部接近原正面方向，身体保持中立，不画大幅左右摇摆，不画残影或速度线。
不画外部人的手、绳子、钩子或新增配件；动作参考按图 C。
保持呆毛完整，不把呆毛拉直或用作悬挂绳。
后续摇晃由程序处理，这张只需要清楚的基础姿势。
```

第二张从已认可的中立帧编辑，只改变手脚、发梢或表情的少量细节，继续锁定身体站位。

## P3：轻微生气表情

```text
编辑目标为已认可的干净正面图；只修改标注的眼眉、嘴和少量脸颊区域。
表情是被连续戳后轻轻鼓脸、略微不满，仍然可爱，不哭、不露攻击性表情。
保留异色瞳、五官位置和原脸型；不要新增牙齿、手势或夸张变形。
脸外的头发、头饰、身体、衣服、比例、画布和透明区域全部保留。
只输出一张鼓脸关键姿势，不把怒气符号烘焙进身体，符号后续另做。
```

## P4：左 / 右边缘探头

先明确两个不同概念：角色藏在屏幕哪一边，以及脸向哪边看。下例是角色藏在左外缘、向屏幕内部看。

```text
沿用通用固定要求，制作角色藏在屏幕左侧边缘、探头向右侧屏幕内部看的姿势。
图 C 的竖线只是定位参考，不要把线或墙画到输出图里。
头和上半身轻轻侧探，一只手可放在预定的边缘位置，身体其他部分仍画完整。
保留完整呆毛、发梢与手脚；不要提前把左半身体硬裁掉，实际遮挡由程序完成。
保持人物自身的异色瞳和爱心发饰方向，不直接把正面图水平镜像。
输出单张关键姿势，透明背景，无墙面、窗框或屏幕截图。
```

右侧重新按相反藏身方向编写，审查身份特征。不要只将左侧成品整图翻转。

## P5：行走缺失关键姿势

```text
目标是同一段行走循环中的一个缺失关键姿势，不是重新设计角色。
图 B1、B2 是已认可的现有行走姿势；图 C 规定这一张经过姿势的手脚位置。
保持身体基准框、头部大小、脚底基线、相机角度、色板与描边一致。
只改变步态相关的腿、手臂、裙摆和少量发梢；脸、头饰和主要发束不漂移。
行走方向为[填写屏幕左 / 右]，全身完整，不增加镜头移动、场景、残影或速度线。
只输出本次指定的一帧，不输出整张 sprite sheet。
```

不要以普通交叉淡入淡出作为腿部中间帧；重影不是新的身体姿势。

## 每次提交附带记录

直接在候选处理记录中填写：动作、修改目标、输入版本、渠道和模型 ID、提示词版本、seed 或请求编号、输出编号、实际费用、待修点与审图状态。seed 为空是合法情况，不能伪造模型不支持的字段。

## 形象与交付约束

正面画面左眼绿、右眼红，爱心发饰在画面右侧；侧身按角色自身方位处理，不能直接镜像改身份。保留粉色长发、呆毛、女仆头饰、裙装与头身比例。

每组动作固定画布、身体基准框、脚底，另记拎起支点或探头边缘锚点；爱心和怒气等特效不计入身体框。序列从 `_0` 连续编号，标明帧率、是否循环、退出规则。以透明 PNG 交付，在深浅底检查白边，确认安全边距；用户审图前保持候选状态。
