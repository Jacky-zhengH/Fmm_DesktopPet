# 芙眠眠 nemu 桌宠 · 便携版

Windows x64，无需安装 Python。把 EXE 放进自己可写的文件夹，双击启动即可；单文件首次解压可能需要等几秒。

常用操作见同目录的 `功能指引.txt`。Release 也提供单独的 `-Guide.txt` 和供修改开发使用的 `-source.zip`；直接使用桌宠只需 EXE 或便携 ZIP。

- 鼠标停在角色上，展开时钟、喂食、设置三个弧形入口。
- 左键点击互动，拖动换位置；靠近任务栏或屏幕边缘松开可吸附。
- 右键直接睡觉/叫醒或退出；设置面板也可以退出。
- 设置中调整大小（80%～200%），也可 Ctrl＋滚轮缩放。
- 悬停时钟在图标附近显示透明时间文字，芙芙用紧凑气泡报日期和星期，短暂显示后收起；点击设置定时。支持预设和自定义时分秒；开始后菜单自动关闭，独立计时器可拖动、暂停和取消。
- 到时芙芙走到屏幕中央提醒，气泡结束后走回出发位置并恢复吸附；提醒后主动拖动则取消自动返回。
- 喂食暂为概念预览，左右切换零食，数值不存档；睡着时先留点心。

个人设置和日志放在 EXE 旁的 `.user` 文件夹。升级时退出旧程序，用新 EXE 替换，保留 `.user` 即可。想恢复默认时，退出后移走 `.user`。

0.1.2 保留现有动作素材，呆毛白色残留尚未清理。正式养成、音乐和直播联动还没有加入。

本版本没有数字签名。请从自己的私有 GitHub Release 获取，并可用随附 SHA256SUMS 核对文件。

源码测试仍使用项目根目录 run.bat；修改源码不会自动更新已经打好的 EXE。
