# 第一阶段 0.1.x：走路大小与任务栏吸附

此文档最初记录了修改方案。按用户确认的版本规则，这些工作属于第一阶段 0.1.x，而不是下一阶段 0.2.x。

下述两项修复来自 `ver0.1.0` 分支。用户已同意移除一键贴边后合并，版本记为 0.1.1。原始 PNG 和 v0.1.0 标签保留。

目前实现：全帧 Alpha 可见区域共用变换，待机/行走保持可见高度和脚底；释放拖动时按 24 个逻辑像素范围吸附，拖入任务栏区域也会贴回上沿；右键保留吸附开关，保存吸附位置。无法识别保留区域时使用屏幕边缘。透明窗口留白可越界，但角色可见部分保持在屏幕内，脚底以下不接收输入。

## 行走时为什么会变小

修复前绘图按 `角色画布大小 / 原图最长边` 缩放，PNG 里的透明留白也参与计算。

| 状态 | 原图 | 有效 Alpha 高度 | 100% 时可见高度 | 底部透明留白 |
|---|---|---:|---:|---:|
| 待机 | 512×512 | 458 px | 约 179 px | 约 10.5 px |
| 行走 | 284×512 | 356 px | 约 139 px | 约 31.3 px |

因此行走的可见高度只有待机的约 77.7%，缩小约 22.3%。这不是用户缩放设置变化，也不是像素显示开关造成的。

修复使用“可见角色框 + 脚底锚点”，保留原始 PNG：

1. 素材库计算每套动作全帧 Alpha bbox 的并集，整套动画共享同一变换，避免逐帧裁剪造成抖动。
2. 以 idle 的可见高度为当前形象参考，行走先使用约 `458 / 356 = 1.287` 的内容补偿，统一落脚基线。不是对整张带留白画布直接放大 1.287 倍，以免裁切。
3. 把变换后的可见轮廓适配到安全绘图区域。后续增加素材配置时，再考虑独立的 anchor / content_scale / bbox，以及嘴、爱心等特效的测量区域；这些配置本次尚未实现。
4. 状态切换固定脚底在屏幕中的坐标，不能只固定窗口底部。
5. 先统一可见高度，之后再检查头部/身体比例；目前两套图构图不同，必要时重做走路母版，不能声称一个数字就修好了画风差别。

验收：相同缩放下 idle/walk 可见高度差异控制在约 5% 内；固定锚点不跳；序列各帧不缩放抖动；160/200/300/400 画布不裁切；原 PNG 哈希不变。

## 为什么拖不到任务栏边上

修复前 `_clamp_to_screen()` 使用 `QScreen.availableGeometry()`，该区域排除了任务栏等保留区域；限制的是整个窗口矩形，而不是角色可见轮廓。另有窗口 padding 和图片底部留白，所以角色脚底会在边界之上悬空。旧版也没有吸附状态、阈值或任务栏锚点。

默认目标为“站在任务栏上沿，脚底贴线”，同时允许用户选择自由放置。不是承诺直接把宠物嵌入系统任务栏或复制 BongoCat 的所有交互。

1. 区分整个屏幕 `geometry()` 与排除任务栏的 `availableGeometry()`：前者限制窗口不会彻底丢失，后者用于推断任务栏/保留区域边缘。
2. 释放拖动时，以可见脚底到边缘的距离判断吸附，当前阈值为 24 个 Qt 逻辑像素；独立计算窗口、绘图区域和角色脚底坐标。
3. 吸附时允许透明的窗口留白延伸进任务栏区域，让可见脚底恰好贴上沿；不能让透明窗口挡住任务栏图标。必要时对透明区域设置点击掩码/命中规则，并验证设置面板仍可操作。
4. 设置增加“靠近边缘时吸附”，支持拖走解除；已有锚点时沿同一基线走动。缩放、换动作、屏幕切换时重新求位置，保留锚点。
5. 左/右/顶部任务栏按实际保留边缘处理；自动隐藏或 geometry 差分无法判断时，提供屏幕边缘回退和手动关闭，不误称检测成功。
6. 多屏移除、DPI 变化和旧配置恢复时重新验证位置，避免跑到不可见区域。

验收：拖近上沿后吸附、拖走解除、关闭吸附后自由放置；任务栏图标仍可点击；点击/睡眠/行走与80%～200%缩放保持脚底；多屏/DPI/自动隐藏需实机测试，不以离屏测试替代。

## 本次验证

2026-10-17，`ver0.1.0` 分支：

- 24 项单元检查通过，覆盖真实素材、全帧定位、80%～200% 缩放、吸附解除/保存、四边任务栏与负坐标屏幕的几何计算。
- Windows 原生 Qt 启动检查通过。当前电脑实测：100% 时待机与走路均约 178.906 逻辑像素高；150% 时约 268.359，脚底和任务栏上沿均为 y=912，睡眠后也保持对齐。
- 原生窗口掩码下沿为 y=912，去掉脚底以下的透明输入区域；尚未逐一实测任务栏图标点击。
- 对照图见 [走路尺寸对照](../analysis/ver0_1_scale_comparison.png)。原始 PNG 未改动。
- 多屏热插拔、混合 DPI 和自动隐藏任务栏尚待实机试用，模拟检查不能代替这些场景。

用户已同意移除一键贴边后合并 PR，版本记为 v0.1.1；移除后的回归检查仍为 24 项通过。

依据：[Qt QScreen 文档](https://doc.qt.io/qt-6/qscreen.html) 说明 availableGeometry 排除任务栏等窗口管理器保留区域。Windows 原生 AppBar 接口若在自动隐藏场景有必要，再加入独立平台适配层。
