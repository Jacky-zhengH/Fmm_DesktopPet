# 芙眠眠nemu桌宠 · 简易功能指引

一只可以放在桌面上陪你的芙芙。目前有基础互动、气泡菜单、时钟和倒计时，喂食还是概念预览。

## 怎么打开

- 直接使用：下载 EXE，放进自己可写的文件夹，双击即可，不用安装 Python。也可以下载便携 ZIP，解压后打开里面的 EXE。
- 修改源码：下载 `-source.zip`，解压后先安装 Python 3.10 或更新版本，第一次双击 `setup.bat` 安装依赖，以后双击根目录 `run.bat`。
- 一次打开一只即可。改了源码后要重新打包，已有的 EXE 才会更新。

## 常用操作

| 想做什么 | 怎么操作 |
|---|---|
| 摸摸芙芙 | 左键点击；睡着时点击会叫醒 |
| 换个位置 | 按住左键拖动；靠近屏幕边缘或任务栏松开可吸附，拖走可解除 |
| 打开菜单 | 鼠标停在芙芙身上片刻，出现时钟、喂食、设置三个气泡；位置会自动避让屏幕边缘 |
| 收起菜单 | 鼠标移开，或按 Esc；面板也可点 × 关闭 |
| 睡觉、叫醒、退出 | 右键直接选择；设置面板里也有这些操作 |
| 调整大小 | 设置 → 调整大小，范围 80%～200%；也可按住 Ctrl 滚动滚轮，普通滚轮不会改大小 |
| 看时间和日期 | 悬停时钟气泡，旁边显示时间，芙芙短暂报出日期和星期 |
| 设倒计时 | 点击时钟，选预设或自定义时分秒；开始后菜单收起，留下独立小计时器，可拖动、暂停、继续或取消 |
| 到点提醒 | 芙芙走到屏幕中央提醒，再走回原位；主动拖动会取消自动返回。关闭计时器会取消计时，退出桌宠后不再计时 |
| 选点心 | 点击喂食，用左右按钮或键盘切换点心，选择 1～3 份；睡着时先留点心。这里只演示效果，数值不会保存 |
| 调整显示和走动 | 设置里可切换像素清晰显示、自主走动和边缘吸附；打开菜单时呼吸和睡眠动画继续 |

鼠标离开后找不到菜单时，也可以点击系统托盘里的芙芙图标。

## 保存和升级

位置、大小和显示选项会保存。EXE 版的设置在 EXE 旁的 `.user` 文件夹；源码版在 `deskpet/deskpet/.user`。

升级前先退出旧桌宠，再替换 EXE，保留 `.user`。不要把个人 `.user` 随压缩包发给别人。
