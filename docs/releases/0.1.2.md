# Fmm-DesktopPet-v0.1.2

0.1.2 就此封盘。程序和文件名保持 0.1.2，本次构建记为 `v0.1.2+build.3`，之前的标签和发布文件保留。

## 当前功能

- 小图标沿弧线排列，按屏幕位置切换方向；右键保留睡觉/叫醒和退出。
- 打开菜单时，待机呼吸、眨眼与睡眠动画继续。
- 悬停时钟以 22px 透明描边文字看时间；日期和星期由芙芙的紧凑语言气泡报出，约 2.4 秒后收起，边角避让菜单。点击设预设或自定义倒计时。开始后菜单自动关闭，独立小窗口可暂停、继续和取消。
- 到时芙芙走到屏幕中央提醒，气泡结束后走回原位并恢复吸附。主动拖动会取消自动返程。
- 点心面板改为紧凑的滑动轮播；睡着时先留点心，喂食数值仍是概念演示，不保存。
- 对话气泡更靠近角色，睡眠时有单独文本。
- 点击互动、拖动移动，靠近任务栏和屏幕边缘释放可吸附；大小可在 80%～200% 调整，也支持 Ctrl＋滚轮。
- 像素清晰/平滑显示、自主走动和边缘吸附可开关，位置及显示设置会保存。

## 下载与运行

- **直接使用**：下载 `Fmm-DesktopPet-v0.1.2.exe`，双击启动，不需要安装 Python。
- **带说明的便携包**：下载 `Fmm-DesktopPet-v0.1.2.zip`，解压后双击其中的 EXE。与单独下载的 EXE 相同。
- **修改源码**：下载 `Fmm-DesktopPet-v0.1.2-source.zip`，解压后先准备 Python 3.10+，第一次运行 `setup.bat`，以后双击根目录 `run.bat`。
- **只看功能**：打开 `Fmm-DesktopPet-v0.1.2-Guide.txt`。SHA256SUMS 用于核对下载是否完整，普通使用不必下载。

设置保存在 EXE 旁的 `.user`，升级前退出旧程序，替换 EXE 并保留 `.user` 即可。

现有动作与原始 PNG 保留，呆毛背景残留、正式养成、音乐台和直播联动留待后续版本。喂食仍为概念演示，定时器需要桌宠保持运行。
