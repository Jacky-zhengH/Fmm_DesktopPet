# Fmm-DesktopPet-v0.1.2

这是 0.1.2 的最终修订，已获用户验收，本版本阶段收尾。程序与文件名保持 0.1.2，构建标签为 v0.1.2+build.2；原来的 v0.1.2 标签和初版文件保留，方便回退。

- 小图标沿弧线排列，按屏幕位置切换方向；右键保留睡觉/叫醒和退出。
- 打开菜单时，待机呼吸、眨眼与睡眠动画继续。
- 悬停时钟以 22px 透明描边文字看时间；日期和星期由芙芙的紧凑语言气泡报出，约 2.4 秒后收起，边角避让菜单。点击设预设或自定义倒计时。开始后菜单自动关闭，独立小窗口可暂停、继续和取消。
- 到时芙芙走到屏幕中央提醒，气泡结束后走回原位并恢复吸附。主动拖动会取消自动返程。
- 点心面板改为紧凑的滑动轮播；睡着时先留点心，喂食数值仍是概念演示，不保存。
- 对话气泡更靠近角色，睡眠时有单独文本。

下载 `.exe` 可直接运行，不需要 Python；也可以下载带使用说明的 `.zip`。两个包中的 EXE 相同，SHA256SUMS 可用于核对文件。设置在 EXE 旁的 `.user`，升级时保留即可。源码开发仍双击根目录 `run.bat`。

验证：58 项 Qt/素材检查通过；Windows 原生计时、中央提醒、返程与睡眠/任务栏吸附恢复流程已运行；单文件 EXE 已启动检查并核对内置角色素材。

现有动作与原始 PNG 保留，呆毛背景残留、正式养成、音乐台和直播联动留待后续版本。定时器需要桌宠保持运行。
