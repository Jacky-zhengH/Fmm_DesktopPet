# Fmm-DesktopPet-v0.1.3

0.1.3 整理了近期的时钟显示和气泡小修订，日常操作沿用 0.1.2。

## 当前功能

- 点击互动、拖动移动、待机呼吸、眨眼、走动和睡眠；右键可睡觉、叫醒或退出。
- 时钟、喂食、设置三个气泡沿弧线排列，会根据屏幕位置换方向。
- 悬停时钟看当前时间，日期和星期由芙芙用短暂语言气泡报出；点击可设预设或自定义倒计时，独立小窗口支持暂停、继续和取消。
- 到时芙芙走到屏幕中央提醒，再回原位并恢复吸附；主动拖动可取消自动返程。
- 调整大小 80%～200%，支持 Ctrl＋滚轮；可切换像素显示、自主走动和边缘吸附，保存位置及显示设置。
- 喂食是概念预览：左右切换零食、选择份数，睡着时先留点心，演示数值不保存。

## 本次更新

- 整理本轮时钟显示调整：时间使用独立的 22px 透明描边文字，移开鼠标即收起；日期和星期使用靠近角色的紧凑气泡，约 2.4 秒自动收起，一次悬停只报一次。
- 时间文字与日期气泡在屏幕边角避让菜单，长文本气泡按实际换行高度显示，避免裁字。
- 精简标准版启动流程，保留原有互动与计时操作。
- 源码包和 EXE 便携包都附简易功能指引，另提供单独的指引及 SHA256 校验文件。

## 下载与运行

- **直接使用**：下载 `Fmm-DesktopPet-v0.1.3.exe`，双击启动，不需要安装 Python。
- **带说明的便携包**：下载 `Fmm-DesktopPet-v0.1.3.zip`，解压后打开其中的 EXE。
- **修改源码**：下载 `Fmm-DesktopPet-v0.1.3-source.zip`，准备 Python 3.10+，第一次运行 `setup.bat`，以后双击根目录 `run.bat`。
- **只看功能**：打开 `Fmm-DesktopPet-v0.1.3-Guide.txt`。SHA256SUMS 可用于核对下载文件，普通使用不必下载。

升级前退出旧桌宠，用新 EXE 替换旧文件并保留旁边的 `.user` 文件夹。定时器需要桌宠保持运行；正式养成、音乐台和直播联动尚未加入，原角色素材保持不变。
